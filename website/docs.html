Twenty Course Deep Curriculum

A detailed teaching blueprint for the V++ course system. Each project is expanded

into concepts, step by step reasoning, code blocks, complete source, expected

behavior, common mistakes, and practice.

Purpose: give Cursor enough structured teaching content to build course pages that

feel like a real programming curriculum instead of five short snippets.

Language basis: the current V++ course pages supplied by the project website, expanded into a deeper instructional format.

Curriculum Map

The twenty projects progress from the smallest executable program to typed data modeling, safe error handling, generic programming, traits, modules, practical algorithms, filesystem work, and JSON configuration. The sequence intentionally reuses earlier ideas so each project adds a small number of new concepts while increasing the size of the program. Global V++ Conventions Used Throughout the Curriculum Program entry: Executable examples use fn main() -> int as the entry point and return 0 for successful completion. Local inference: let infers the local type from the initializer. Use let mut when a local binding must be reassigned. Functions: Function parameters and return types are explicit. This keeps public function contracts visible while locals remain concise. Blocks: Braces define function, conditional, loop, match, struct, trait, and implementation bodies. Printing: print evaluates its argument and writes the result to standard output. Checking: When an example fails, use vpp check first. Fix the first diagnostic before changing unrelated code. Native execution: The same source can be run through the V++ toolchain and compiled to native code. Course pages should encourage learners to verify both paths when practical.

Project 01: Hello World

Level: Beginner

Project goal: Build the smallest complete V++ program and understand the program entry point, output, and exit status.

Core concepts

fn main() -> int, print, return, program entry point

Step 1: Create the entry point

Every executable V++ program needs a place where execution begins. The function named main is that entry point.

Its return type is int because the operating system receives the integer status when the program finishes.

The braces define the body of main. Statements inside the body execute in order. The print call sends a string to standard output. The return statement finishes main and gives the operating system a success status.

Type the code yourself first. Then run it with vpp run.

After typing the snippet, identify the new names introduced by the step. Ask what each name represents, what type the compiler should infer or check, and what value should exist after the code runs.

    print("Hello, v++!")
    return 0
}

Execution starts at main. A function signature is part of the language contract. Printing and returning are separate operations.

Step 1: Sum an array

An array type describes the element type inside square brackets. The sum function accepts array[int], so the compiler knows every element is an integer.

total must be mutable because each loop iteration updates it. The for loop gives n one element at a time.

    for n in nums {

}

Step 2: Find the largest value

Indexing uses square brackets. nums[0] reads the first element and gives best its inferred integer type.

Each element is compared with best. When a larger value is found, best is replaced. This demonstrates how arrays and mutable local state work together.

fn max_of(nums: array[int]) -> int {
    let mut best = nums[0]
    for n in nums {
        if n > best {
            best = n
        }

    return best
}

Step 1: Return Result from division

Result is useful when a function can either produce a value or explain why it could not. safe_div returns Result<int, string>. A zero divisor becomes Err, while a valid division becomes Ok.

After typing the snippet, identify the new names introduced by the step. Ask what each name represents, what type the compiler should infer or check, and what value should exist after the code runs.

main.vpp
fn safe_div(a: int, b: int) -> Result<int, string> {
    if b == 0 {
        return Err("division by zero")
    }
    return Ok(a / b)
}

Step 2: Return Option from a search

Option represents presence or absence. find_first returns Some when it finds the target and None when the loop finishes without finding it.

The mutable index is necessary because the search advances one position at a time.

fn find_first(nums: array[int], target: int) -> Option<int> {
    let mut i = 0
    while i < len(nums) {
        if nums[i] == target {
            return Some(nums[i])
        }
        i = i + 1
    }
    return None
}

VS Code Extension

Official IDE support — syntax highlighting, run with F5, diagnostics, IntelliSense, and project tests. Extension ID: vpp-lang.vplusplus

Install step by step

1

Install the v++ compiler first

The extension does not bundle the compiler. Download and run vpp-0.5.0-setup.exe from Download.

vpp doctor
2

Open VS Code Extensions

Press Ctrl+Shift+X (Windows) or Cmd+Shift+X (macOS).

3

Search and install

Search v++ Language. Verify the publisher is vpp-lang — other "V++" extensions are unrelated.

Open on Marketplace
4

Reload VS Code

After install, reload the window. Open any .vpp file — bottom-right should show language mode v++.

5

Run your first program

Open a folder with .vpp files. Press F5 or Ctrl+Shift+R to run the active file.

vpp run examples\hello.vpp
6

Enable IntelliSense (optional)

Release builds include vppls (language server). In Settings, search vpp:

  • vpp.compilerPath — path to vpp.exe if not on PATH
  • vpp.languageServerPath — path to vppls
  • vpp.enableLanguageServer — red squiggles, completion, go-to-definition

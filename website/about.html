About v++

An open-source programming language — designed, implemented, and shipped by one person. Everything is on GitHub. No secrets.

The idea

Write it simply. Compile it natively. Grow into control when you need it.

Python proved that readable syntax matters. Rust and C proved that native speed matters. v++ asks: what if you didn't have to pick one on day one?

  • Start with vpp run — instant feedback, no build step
  • Add types when you want safety — inference handles the easy cases
  • Ship with vpp build — real native executables via LLVM

Built in the open

Every line of the compiler is MIT licensed on GitHub:

  • Lexer & parser — hand-written, from scratch
  • Type checker — generics, traits, exhaustiveness
  • Two backends — interpreter + LLVM codegen
  • Language server — diagnostics, completion in VS Code
  • Package manager — vpp.toml, dependencies, lockfile
  • Standard library — io, fs, json, process, and more
  • Distribution — CI, Windows installer, Marketplace extension

Design principles

Readable first

Syntax should feel like Python — minimal punctuation, obvious flow. Types when they help, not when they hurt.

Correct by default

Immutable bindings, exhaustive match, static types. Catch mistakes at compile time, not in production.

Honest about stage

v0.5 is pre-1.0. The spec can still change. We'd rather ship real software and improve it than pretend it's finished.

Fully open

MIT license. No telemetry. No walled garden. Fork it, learn from it, build on it.

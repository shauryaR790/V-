FizzBuzz

Classic loop exercise divisibility and conditionals.

What you will build

Classic loop exercise — divisibility and conditionals. By the end you will understand `%`, `while`, functions. We build the program in layers, run snippets mentally, then execute the full source.

2

Learning goals

Level: Intermediate. Read each step before copying code. Types are enforced at compile time, so fix signature errors early with vpp check.

3

Function: fizzbuzz

Functions encapsulate reusable logic with explicit parameter and return types. V++ requires a typed signature; locals may be inferred. In this step we add function: fizzbuzz to the growing program.

main.vpp
fn fizzbuzz(n: int) -> string {
    if n % 15 == 0 {
        return "FizzBuzz"
    }
    if n % 3 == 0 {
        return "Fizz"
    }
    if n % 5 == 0 {
        return "Buzz"
    }
    return "num"
}
4

Entry point: main

Every executable program defines fn main() -> int. The integer return value becomes the process exit code (0 means success). In this step we add entry point: main to the growing program.

main.vpp
fn fizzbuzz(n: int) -> string {
    if n % 15 == 0 {
        return "FizzBuzz"
    }
    if n % 3 == 0 {
        return "Fizz"
    }
    if n % 5 == 0 {
        return "Buzz"
    }
    return "num"
}

fn main() -> int {
    let mut i = 1
    while i <= 20 {
        let label = fizzbuzz(i)
        if label == "num" {
            print(i)
        } else {
            print(label)
        }
        i = i + 1
    }
    return 0
}

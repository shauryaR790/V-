What you will build

Enums is project 07 in the V++ curriculum (Intermediate level). Sum types with named variants and pattern matching.

In this walkthrough you will not paste the whole file at once. Each step introduces one idea, explains what the lines mean, and shows only the new snippet. By the end you will combine everything into a complete program that produces Stop, Go.

The key ideas here are enum, variants, and match. Read the prose under every heading before you look at code. When you reach the playground, run the full source with vpp run projects/07-enums/main.vpp on your machine or use the Run button to compare against the expected output.

Learning goals

After finishing Enums, you should be able to explain enum, variants, and match in your own words and reproduce the program without copying blindly.

You should already be comfortable with variables, functions, and loops from projects 01 through 05.

Use vpp check on your file when something fails to compile. The type checker reports signature mismatches early. Fix one error at a time, then re-run.

Enum: TrafficLight

Step 1 of 4 for Enums. We now add Enum: TrafficLight to the program.

We introduce Enum: TrafficLight with enum TrafficLight {. An enum lists every legal variant up front, which prevents impossible states later when you match on it.

Variants Red, Yellow, Green, } are the only allowed values. Adding a new variant later means updating every match that uses this enum.

Study the snippet below. It is only the new piece for this step; earlier definitions are assumed to exist above it in your file.

main.vpp
enum TrafficLight {
    Red
    Yellow
    Green
}

Struct: Signal

Step 2 of 4 for Enums. We now add Struct: Signal to the program.

Struct: Signal defines a product type: struct Signal {. Structs group fields that belong together so you pass one value instead of many separate parameters.

Fields light: TrafficLight are checked at compile time. You construct values with struct literal syntax { field: value }.

Study the snippet below. It is only the new piece for this step; earlier definitions are assumed to exist above it in your file.

main.vpp
struct Signal {
    light: TrafficLight
}

Function: action

Step 3 of 4 for Enums. We now add Function: action to the program.

Function: action adds fn action(signal: Signal) -> string {. Parameters and return types are required on function signatures; the body must return a value compatible with that return type on every path.

match signal.light { inspects a value and selects the first arm whose pattern fits. V++ requires match expressions to be exhaustive over the type.

The arm Red => { handles one case. When it matches, the code after => runs.

return "stop" sends a value back to the caller and ends the current function.

The arm Yellow => { handles one case. When it matches, the code after => runs.

return "slow" sends a value back to the caller and ends the current function.

The arm Green => { handles one case. When it matches, the code after => runs.

return "go" sends a value back to the caller and ends the current function.

Study the snippet below. It is only the new piece for this step; earlier definitions are assumed to exist above it in your file.

main.vpp
fn action(signal: Signal) -> string {
    match signal.light {
        Red => {
            return "stop"
        }
        Yellow => {
            return "slow"
        }
        Green => {
            return "go"
        }
    }
}
6

Entry point: main

Step 4 of 4 for Enums. We now add Entry point: main to the program.

fn main() -> int is the program entry point. The runtime calls it after your definitions are loaded. Everything inside the braces runs in order.

let stop = Signal { light: Red } binds the name stop to a value. V++ infers the type from the right hand side so you rarely need to write it explicitly for simple literals.

let go = Signal { light: Green } binds the name go to a value. V++ infers the type from the right hand side so you rarely need to write it explicitly for simple literals.

print(action(stop)) writes to standard output followed by a newline. print accepts values such as integers and strings.

print(action(go)) writes to standard output followed by a newline. print accepts values such as integers and strings.

return 0 exits main with status code 0, which operating systems treat as success. Non-zero values signal an error.

Study the snippet below. It is only the new piece for this step; earlier definitions are assumed to exist above it in your file.

main.vpp
fn main() -> int {
    let stop = Signal { light: Red }
    let go = Signal { light: Green }
    print(action(stop))
    print(action(go))
    return 0
}

Full program & run

Complete source for Enums. Run locally with vpp run projects/07-enums/main.vpp or use the playground below.

main.vpp
enum TrafficLight {
    Red
    Yellow
    Green
}

struct Signal {
    light: TrafficLight
}

fn action(signal: Signal) -> string {
    match signal.light {
        Red => {
            return "stop"
        }
        Yellow => {
            return "slow"
        }
        Green => {
            return "go"
        }
    }
}

fn main() -> int {
    let stop = Signal { light: Red }
    let go = Signal { light: Green }
    print(action(stop))
    print(action(go))
    return 0
}

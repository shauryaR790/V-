contributing — building-from-source

Building from source

Requirements

  • Rust (stable) — rustup.rs
  • LLVM 22 + clang (for codegen feature)
  • Git (for git dependencies in tests)

Build


git clone https://github.com/shauryaR790/V-.git
cd V-
cargo build --release --features codegen,lsp

Windows:


$env:LLVM_SYS_221_PREFIX = "C:\Program Files\LLVM"

Binaries: target/release/vpp.exe, target/release/vppls.exe.

Features

FeatureEnables
*(default)*Interpreter, checker, fmt, CLI
codegenNative vpp build, LLVM
lspvppls language server

Install locally


cargo install --path . --features codegen,lsp

getting-started — hello-world

Hello, v++

Create hello.vpp:


fn main() -> int {
    print("Hello from v++!")
    return 0
}

Run it:


vpp run hello.vpp

Type-check without running:


vpp check hello.vpp

Compile to a native executable:


vpp build hello.vpp -o hello.exe
.\hello.exe

What you just used

  • vpp run — interpreter (fast iteration, no compile step)
  • vpp check — type checker only
  • vpp build — LLVM + clang → .exe

Windows (recommended)

1. Download vpp-0.5.0-setup.exe from GitHub Releases.

2. Run the installer. If Windows SmartScreen appears, choose More info → Run anyway.

3. Open a new terminal:

$dir = "$env:LOCALAPPDATA\Programs\vpp"
[Environment]::SetEnvironmentVariable("Path", $env:Path + ";$dir;$dir\llvm\bin", "User")

Restart the terminal.

guides — language-server

Language server (vppls)

vppls provides:

  • Diagnostics — red squiggles from the type checker
  • Completion — keyword and context suggestions
  • Go to definition — jump to symbols (best-effort)

Build


cargo build --release --features lsp --bin vppls

Disable with vpp.enableLanguageServer: false.

Standard LSP over stdio. Started automatically by the VS Code extension when a .vpp file is open.

<!-- guides\native-compilation.md -->

guides — native-compilation

Native compilation

vpp build lowers code to LLVM IR, compiles with clang, and links the v++ C runtime.


vpp build examples/hello.vpp -o hello.exe
.\hello.exe

Requirements

  • Release installer — includes portable clang under llvm\bin
  • From source — LLVM 22 + LLVM_SYS_221_PREFIX

$env:LLVM_SYS_221_PREFIX = "C:\Program Files\LLVM"
cargo build --release --features codegen

Interpreter vs native

vpp runvpp build
Speed to iterateFastSlower
OutputRuns in VMStandalone .exe
LLVM neededNoYes

Parity tests ensure interpreter and native produce the same stdout for key examples.

Memory model

Strings and arrays use ARC in native code. See MEMORY_MODEL.md.

<!-- guides\troubleshooting.md -->

guides — troubleshooting

Troubleshooting

vpp not recognized

  • Reopen terminal after install
  • Add install dir to PATH (see install guide)
  • Or set vpp.compilerPath in VS Code

SmartScreen / security warning

Open-source installers may trigger a one-time Windows SmartScreen prompt. Choose More info → Run anyway, or verify the download from GitHub Releases.

vpp build fails — clang not found

  • Use release installer (bundled clang), or
  • winget install LLVM.LLVM and set LLVM_SYS_221_PREFIX

No syntax highlighting

  • Install extension v++ Language (vpp-lang)
  • Reload window; confirm language mode is v++

LSP not working

  • Build vppls: cargo build --features lsp --bin vppls
  • Check Output panel → v++ Language Server

Native vs interpreter mismatch

Run parity check:


.\stress.ps1

File issues: GitHub Issues.

<!-- language\control-flow.md -->

language — control-flow

Control flow

if / else


if x > 0 {
    print("positive")
} else {
    print("non-positive")
}

while


let mut i = 0
while i < 3 {
    print(i)
    i = i + 1
}

for (range)


for i in 0..3 {
    print(i)
}

for (array)


for name in ["Alex", "Sam"] {
    print(name)
}

match


match status {
    Active => print("on"),
    Idle => print("off"),
}

Enums, Option, and Result matches must be exhaustive or use _ (compile error E0107).

See option-result-match.md.

break / continue

Supported inside while and for loops.

<!-- language\generics.md -->

language — generics

Generics (v0.4+)

v++ uses monomorphization — generic functions are specialized at each call site.


fn first[T](items: array[T]) -> Option[T] {
    if len(items) == 0 {
        return None
    }
    return Some(items[0])
}

Call with explicit type args:


let word = first[string](["a", "b"])

Example: examples/generics.vpp.

<!-- language\mut-and-immutability.md -->

language — mut-and-immutability

mut and immutability (v0.4+)

Bindings are immutable by default.


let x = 1
// x = 2   // error: cannot reassign immutable binding

Use mut when you need to reassign:


let mut count = 0
count = count + 1

Loop counters and accumulators typically need mut.

<!-- language\option-result-match.md -->

language — option-result-match

Option, Result, and match

Option


let some = Some(42)
let none: Option[int] = None

Result


fn divide(a: int, b: int) -> Result[int, string] {
    if b == 0 {
        return Err("division by zero")
    }
    return Ok(a / b)
}

Exhaustive match

The compiler rejects non-exhaustive matches on enums, Option, and Result:


match opt {
    Some(x) => print(x),
    None => print("empty"),
}

Missing None → E0107.

Use _ for a catch-all when appropriate.

Traits and impls (v0.4+)

Static dispatch — no virtual tables at runtime.


trait Display {
    fn to_text(self) -> string

    name: string,

impl Display for User {
    fn to_text(self) -> string {
        return self.name
    }
}

let u = User { name: "Alex" }
print(u.to_text())

Privacy Policy — v++

Last updated: August 2026

v++ (the compiler, language server, and VS Code extension) is open-source software distributed under the MIT License.

Data collection

The v++ compiler and language server do not collect, transmit, or store personal data. All compilation and analysis runs locally on your machine.

The VS Code extension communicates only with the local vppls language server process on your computer. It does not send source code or usage data to any remote server operated by the v++ project.

Third-party services

  • GitHub Releases — if you download binaries from GitHub, GitHub’s own privacy policy applies to that download.
  • VS Code Marketplace — if you install the extension from the Marketplace, Microsoft’s privacy policy applies to that installation flow.

Contact

Appendix — extended reference

Lexical structure (reference §1)

v++ source files use UTF-8 encoding. Line comments begin with //. Block comments are not yet supported. Identifiers match [A-Za-z_][A-Za-z0-9_]*. Keywords are reserved.

See also: language docs, learn guide, GitHub source.


// Example stub for documentation section
fn main() -> int {
    print("v++ v0.5.0")
    return 0
}

Numeric literals (reference §2)

Integer literals are decimal sequences parsed as 64-bit signed int. Float literals contain a decimal point and parse as IEEE 64-bit float.

See also: language docs, learn guide, GitHub source.


// Example stub for documentation section
fn main() -> int {
    print("v++ v0.5.0")
    return 0
}

String literals (reference §3)

Double-quoted strings support escape sequences for newline and quotes. Strings are immutable in v++ and use heap storage in native mode with ARC.

See also: language docs, learn guide, GitHub source.

    print("v++ v0.5.0")
    return 0
}

Boolean literals (reference §4)

The literals true and false have type bool and appear in conditions and assert calls.

See also: language docs, learn guide, GitHub source.


// Example stub for documentation section
fn main() -> int {
    print("v++ v0.5.0")
    return 0
}

Array literals (reference §5)

Syntax [a, b, c] creates array[T] where T is inferred from elements. All elements must share the same type.

See also: language docs, learn guide, GitHub source.

    print("v++ v0.5.0")
    return 0
}

Struct literals (reference §6)

Struct values use Name { field: value, field2: value2 } with comma-separated fields matching the struct definition order optionally by name.

See also: language docs, learn guide, GitHub source.

}

Function declarations (reference §7)

Functions use fn name(params) -> ReturnType { body }. Generic functions add [T] after the name. Return type may be omitted for void-like functions returning unit in future versions.

See also: language docs, learn guide, GitHub source.


// Example stub for documentation section
fn main() -> int {
    print("v++ v0.5.0")
    return 0
}

Main entry point (reference §8)

fn main() -> int is invoked by both interpreter and native codegen. Return code propagates to process exit status on native builds.

See also: language docs, learn guide, GitHub source.

Import paths (reference §9)

import std.module resolves relative to the std/ directory in VPP_HOME or project root. Quoted imports load relative paths for legacy single-file modules.

Learn v++

A structured path from zero to building real programs. Each lesson links to docs, examples, and a hands-on project.

Before you start

1

Install the compiler

Download vpp-0.5.0-setup.exe from Download. Open a new terminal and run vpp doctor.

2

Install VS Code extension

Follow the VS Code setup guide — search v++ Language (publisher: vpp-lang).

3

Run your first file

vpp run examples\hello.vpp

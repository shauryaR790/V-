Version history

From first interpreter to Marketplace extension and Windows installer — every major release documented in the open.

v0.5.0August 18, 2026

Documentation & distribution polish

  • 30+ documentation guides (getting started, language, stdlib)
  • Windows installer adds vpp and clang to PATH
  • VS Code extension v0.5.0 on Marketplace
  • CONTRIBUTING, SECURITY, CODE_OF_CONDUCT
v0.4.4August 18, 2026

Ship to users

  • Windows installer (vpp-*-setup.exe) and portable zip
  • Extension published: vpp-lang.vplusplus
  • GitHub Actions release workflow on tags
v0.4.0August 18, 2026

Modern language features

  • mut keyword — immutability by default
  • Generics with monomorphization
  • Traits and static dispatch
  • Compile-time match exhaustiveness
v0.3.0August 18, 2026

Ecosystem

  • Module system (import std.*)
  • Package manager (vpp.toml, lockfile, registry)
  • Standard library: io, math, string, collections, fs, json, process
  • Language server (vppls) + LSP diagnostics
v0.2.0August 18, 2026

Native compiler foundation

  • v++ IR between typed AST and LLVM
  • Native structs, enums, Option/Result, match
  • Interpreter/native parity test suite
  • ARCHITECTURE.md, MEMORY_MODEL.md, SPEC.md
v0.1.0August 2026

First release

  • Tree-walking interpreter for full language subset
  • Partial LLVM backend
  • CLI (vpp run, check)
  • VS Code syntax highlighting extension
  • CI on GitHub Actions

Road to v1.0

Next: REPL, expanded stdlib, code signing, debugger, Test Explorer, frozen spec. Track progress on roadmap.

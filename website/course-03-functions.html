What you will build

Functions is project 03 in the V++ curriculum (Beginner level). Define functions with typed parameters and return values.

In this walkthrough you will not paste the whole file at once. Each step introduces one idea, explains what the lines mean, and shows only the new snippet. By the end you will combine everything into a complete program that produces 30, Hello, Shaurya.

The key ideas here are fn, return, and function signatures. Read the prose under every heading before you look at code. When you reach the playground, run the full source with vpp run projects/03-functions/main.vpp on your machine or use the Run button to compare against the expected output.

2

Learning goals

After finishing Functions, you should be able to explain fn, return, and function signatures in your own words and reproduce the program without copying blindly.

This is an early project: focus on syntax, naming, and how the compiler reads your file top to bottom.

Use vpp check on your file when something fails to compile. The type checker reports signature mismatches early. Fix one error at a time, then re-run.

Tip: type out each snippet yourself instead of copy-pasting. Muscle memory matters for braces, commas, and return types.

5

Entry point: main

Step 3 of 3 for Functions. We now add Entry point: main to the program.

fn main() -> int is the program entry point. The runtime calls it after your definitions are loaded. Everything inside the braces runs in order.

print(add(10, 20)) writes to standard output followed by a newline. print accepts values such as integers and strings.

print(greet("Shaurya")) writes to standard output followed by a newline. print accepts values such as integers and strings.

return 0 exits main with status code 0, which operating systems treat as success. Non-zero values signal an error.

Study the snippet below. It is only the new piece for this step; earlier definitions are assumed to exist above it in your file.

main.vpp
fn main() -> int {
    print(add(10, 20))
    print(greet("Shaurya"))
    return 0
}

Privacy Policy

Last updated: August 2026

This Privacy Policy describes how the V++ open source project (“V++”, “we”, “us”) handles information when you use:

  • the website at shauryaR790.github.io/V-;
  • the V++ compiler (vpp), language server (vppls), and standard library;
  • the V++ Language VS Code extension (publisher: vpp-lang).

Summary

V++ is local first software. We do not operate a backend that receives your source code, compile logs, or personal profile data.

Information we do not collect

The compiler, language server, and VS Code extension:

  • do not send your source code to V++ servers (there are none);
  • do not collect analytics, telemetry, or crash reports by default;
  • do not require an account to build or run programs.

Website

This static site is hosted on GitHub Pages. When you visit, GitHub may process standard web server logs (IP address, browser type, pages viewed) under GitHub’s Privacy Statement.

We do not use third party advertising trackers or social widgets on the site.

Cookies and local storage

See our Cookie Policy. The site does not set marketing cookies.

Third party services

Service When it applies Their policy
GitHub Downloads, issues, Pages hosting GitHub Privacy
VS Code Marketplace Extension install/update Microsoft Privacy
Google Fonts (optional) Site typography CDN Google Privacy

If you clone the repo and self host the site without Google Fonts, that CDN request does not occur.

Children

V++ is developer tooling not directed at children under 13. We do not knowingly collect personal information from children.

Changes

We may update this policy. The “Last updated” date at the top will change when we do.

Contact

Privacy questions: GitHub Issues (label privacy if available).

Why v++ exists

Most languages force a tradeoff: easy to write (Python) or fast to run (C/Rust). v++ is an experiment in having both — readable syntax you can learn in an afternoon, with a compiler that emits native binaries when you're ready.

Built by Shaurya as a real, shippable language — not a parser demo. Interpreter for learning. LLVM for production. Everything open.

Function: total_chars

Step 1 of 3 for Word Counter. We now add Function: total_chars to the program.

Function: total_chars adds fn total_chars(words: array[string]) -> int {. Parameters and return types are required on function signatures; the body must return a value compatible with that return type on every path.

let mut total = 0 creates a mutable binding. You can reassign total later (for example in a loop). The compiler still tracks its type after each assignment.

total = total + len(w) reassigns total. This only works when total was declared with let mut.

return total sends a value back to the caller and ends the current function.

Study the snippet below. It is only the new piece for this step; earlier definitions are assumed to exist above it in your file.

main.vpp
fn total_chars(words: array[string]) -> int {
    let mut total = 0
    for w in words {
        total = total + len(w)
    }
    return total
}

Full program & run

Complete source for Word Counter. Run locally with vpp run projects/16-word-counter/main.vpp or use the playground below.

main.vpp
fn total_chars(words: array[string]) -> int {
    let mut total = 0
    for w in words {
        total = total + len(w)
    }
    return total
}

fn longest_word(words: array[string]) -> string {
    let mut best = words[0]
    for w in words {
        if len(w) > len(best) {
            best = w
        }
    }
    return best
}

fn main() -> int {
    let words = ["v++", "is", "a", "compiled", "language"]
    print(len(words))
    print(total_chars(words))
    print(longest_word(words))
    return 0
}

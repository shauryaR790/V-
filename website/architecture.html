How v++ is built

The entire compiler, runtime, language server, and VS Code extension are open source on GitHub. Written in Rust. MIT licensed.

Compiler pipeline

.vpp source │ ▼ Lexer (src/lexer) │ ▼ Parser → AST (src/parser, src/ast) │ ▼ Module loader (src/modules) │ ▼ Type checker (src/types) → TypedProgram │ ├─────────────────────────┐ ▼ ▼ Interpreter IR lower (src/ir) (src/interp) │ ▼ v++ IR (src/ir) │ ▼ LLVM emit (src/codegen) │ ▼ C runtime (runtime/vpp_runtime.c) │ ▼ native .exe

Two backends, one language

Interpreter

Tree-walking evaluation. Fast feedback for learning and development. Powers vpp run.

Native compiler

Lowers to v++ IR, emits LLVM, links C runtime. Powers vpp build for standalone executables.

Both consume the same typed AST. Parity tests in tests/parity/ ensure interpreter and native output match.

# FAQ

## What is v++?

A compiled language with Python-like syntax, static typing, and native codegen via LLVM.

## Is v++ ready for production?

It's **v0.4** — early but real. Expect language changes until v1.0.

## How is v++ different from Python?

| | Python | v++ |
|---|--------|-----|
| Typing | Dynamic (optional hints) | Static + inference |
| Run | Interpreter default | Interpreter + native `.exe` |
| Ecosystem | Huge | Small, growing |
| Age | 30+ years | New |

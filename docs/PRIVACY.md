# Privacy Policy — v++

**Last updated:** August 2026

v++ (the compiler, language server, and VS Code extension) is open-source software distributed under the MIT License.

## Data collection

The v++ compiler and language server **do not collect, transmit, or store personal data**. All compilation and analysis runs locally on your machine.

The VS Code extension communicates only with the local `vppls` language server process on your computer. It does not send source code or usage data to any remote server operated by the v++ project.

## Third-party services

- **GitHub Releases** — if you download binaries from GitHub, GitHub’s own privacy policy applies to that download.
- **VS Code Marketplace** — if you install the extension from the Marketplace, Microsoft’s privacy policy applies to that installation flow.

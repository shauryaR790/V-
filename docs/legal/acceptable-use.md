# Acceptable Use

**Last updated:** August 2026

V++ is open-source developer tooling. We expect users and contributors to use it lawfully and respectfully.

## You may

- compile, run, and ship applications written in V++;
- fork, modify, and redistribute the compiler under the MIT License;
- report bugs and contribute improvements via GitHub;
- teach, blog, and create courses about V++.

## You may not

- use V++ to develop malware, exploit kits, or tools whose primary purpose is to harm systems or people;
- abuse GitHub Issues, Discussions, or community channels (spam, harassment, hate speech);
- misrepresent modified builds as official V++ releases without clear labeling;
- attempt to compromise project infrastructure (GitHub, release signing, Marketplace publisher account).

## Enforcement

Violations may result in:

- issue/PR closure;
- temporary or permanent ban from project spaces;
- referral to platform abuse teams (GitHub, Microsoft Marketplace) where applicable.

We prefer education and warnings for good-faith mistakes.

## Security research

Good-faith security research is welcome when it follows [SECURITY.md](https://github.com/shauryaR790/V-/blob/main/SECURITY.md).
